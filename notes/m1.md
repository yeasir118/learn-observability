## TS-026: React frontend app

**1. What's in `dist/` after a build, and why do asset names contain a hash?**
`index.html`, `favicon.svg` (copied as is from `public/`), and one JavaScript and one CSS file under `assets/`, e.g. `index-Ba3rw7DJ.js`. The hash is computed from the file's content: it changes exactly when the content changes. So a name identifies one exact version of a file, and a browser can cache it forever; a new build produces new names. `index.html` is the one file whose name never changes and which points at the current names, so it must never be cached (TS-015, decision 6).

**2. Dev and built app call the same `/api/...` URLs. Who answers them?**
Always the origin the page came from, so the browser never knows what's behind it, and there's no CORS:
- `npm run dev` / `npm run preview`: Vite's server, which proxies to `GATEWAY_URL` (default `localhost:5100`). With nothing there, Vite answers its own empty `text/plain` 502.
- In the container (TS-015): nginx, which proxies to `gateway:8080`.
